# 星辰银行核心业务系统 接口需求文档

**文档版本**：v1.0  
**项目**：星辰银行核心业务 API 自动化测试框架  
**编写者**：YANGKAdj  
**更新日期**：2026-01

---

## 一、背景与目标

本文档定义了星辰银行核心交易系统的后端接口功能需求，作为接口自动化测试用例的设计依据。  
测试覆盖范围：用户鉴权模块、账户管理模块、存取款模块、行内及跨行转账模块、安全防护模块、并发竞态场景。

---

## 二、模块需求说明

### 2.1 用户鉴权模块（Auth）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-01 | 用户使用合法手机号、用户名、密码注册新账号 | 注册成功，返回含 `BANK_TOKEN_` 前缀的访问令牌，HTTP 200 |
| REQ-02 | 已注册的手机号不允许重复注册 | 返回 HTTP 400，提示"手机号已存在" |
| REQ-03 | 用户名长度不得少于 3 位 | 返回 HTTP 422（Pydantic 拦截），注册失败 |
| REQ-04 | 密码长度不得少于 6 位 | 返回 HTTP 422，注册失败 |
| REQ-05 | 已注册用户可使用正确的用户名和密码登录 | 登录成功，返回 Token |
| REQ-06 | 使用不存在的用户名登录，系统应拒绝 | 返回 HTTP 404，提示"用户不存在" |
| REQ-07 | 使用错误密码登录，系统应拒绝 | 返回 HTTP 401，提示"密码错误" |
| REQ-08 | 同一账户连续 5 次密码错误后，账户应被临时锁定，拒绝进一步登录尝试 | 第 6 次登录返回 HTTP 403，提示"账户已锁定" |
| REQ-09 | 登录接口应对 SQL 注入 Payload（如 `' OR 1=1 --`）进行有效防护 | 系统不执行注入语句，返回正常的鉴权失败信息 |

### 2.2 账户管理模块（Account）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-10 | 已登录用户可以开通一个活期账户（current）或储蓄账户（savings） | 开户成功，返回内部账号（account_no），HTTP 200 |
| REQ-11 | 不支持的账户类型（如 "vip"）不允许开户 | 返回 HTTP 400，提示非法账户类型 |
| REQ-12 | 用户可以通过合法的账号查询账户详细信息 | 返回账户类型、状态、余额，HTTP 200 |
| REQ-13 | 查询不存在账号的详情，系统应拒绝 | 返回 HTTP 404 |
| REQ-14 | 用户可以查询自身账户的实时余额 | 返回精确余额数值，HTTP 200 |
| REQ-15 | 用户可以注销余额为 0 的账户 | 注销成功，HTTP 200 |
| REQ-16 | 余额大于 0 的账户不允许直接注销 | 返回 HTTP 400，提示"账户余额不为零" |
| REQ-17 | 未携带 Token 或 Token 格式非法的请求，系统应统一拦截 | 返回 HTTP 401 |

### 2.3 存取款模块（Deposit & Withdraw）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-18 | 用户可以向自身账户存入合法金额（正整数，≤ 50 万） | 存款成功，账户余额同步更新，HTTP 200 |
| REQ-19 | 存款金额为 0 或负数，系统应拒绝（Pydantic 拦截） | 返回 HTTP 422 |
| REQ-20 | 单笔存款金额超过 50 万，系统应拒绝 | 返回 HTTP 400 |
| REQ-21 | 存款后，通过数据库 `bank_accounts` 表可核实账户余额与 API 返回值一致（余额一致性） | 接口返回余额 == SELECT balance 结果 |
| REQ-22 | 用户可以从账户中取出合法金额（正整数，≤ 5 万，且不超过当前余额） | 取款成功，账户余额同步扣减，HTTP 200 |
| REQ-23 | 取款金额超过账户当前余额，系统应拒绝 | 返回 HTTP 400，提示"余额不足" |
| REQ-24 | 单笔取款金额超过 5 万，系统应拒绝 | 返回 HTTP 400 |
| REQ-25 | 取款金额为 0 或负数，系统应拒绝 | 返回 HTTP 422 |
| REQ-26 | 取款后，通过数据库核实账户余额是否已精确扣减（余额一致性防资损） | 接口返回余额 == SELECT balance 结果 |

### 2.4 转账模块（Transfer）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-27 | 用户可以将资金从本人账户行内转账至同行其他账号 | 转账成功，双方余额即时更新，HTTP 200 |
| REQ-28 | 转账金额超过付款方余额，系统应拒绝 | 返回 HTTP 400，提示余额不足 |
| REQ-29 | 转账金额为负数，系统应拒绝 | 返回 HTTP 422 |
| REQ-30 | 转入转出账号相同，系统应拒绝（防自转） | 返回 HTTP 400 |
| REQ-31 | 收款账号不存在，系统应拒绝 | 返回 HTTP 404 |
| REQ-32 | 转账后，通过数据库同时核实付款方余额减少与收款方余额增加（双账一致性） | 付款方 balance 减 X == 收款方 balance 加 X |
| REQ-33 | 转账后，`transactions` 交易流水表应生成一条类型为 `transfer` 的账单记录 | SELECT txn_id 可查到，金额与类型一致 |
| REQ-34 | 用户可以发起跨行转账（转入外部账号），系统应收取 0.1% 手续费并由付款方承担 | 付款方余额减少 = 转账金额 + 手续费，HTTP 200 |
| REQ-35 | 跨行转账时，付款方余额不足以覆盖本金+手续费，系统应拒绝 | 返回 HTTP 400 |

### 2.5 安全防护模块（Security）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-36 | 用户 A 持有合法 Token，不得访问用户 B 的账户详情（水平越权防护） | 返回 HTTP 403 |
| REQ-37 | 用户 A 持有合法 Token，不得对用户 B 的账户直接发起取款 | 返回 HTTP 403 |
| REQ-38 | 用户 A 持有合法 Token，不得以用户 B 账户为付款方发起转账 | 返回 HTTP 403 |
| REQ-39 | 存款接口的金额字段应拒绝负数参数（参数篡改防护） | 返回 HTTP 422 |
| REQ-40 | 转账接口的金额字段应拒绝负数参数 | 返回 HTTP 422 |
| REQ-41 | 未携带 Token 的请求访问任意账户信息，系统应统一拒绝 | 返回 HTTP 401 |
| REQ-42 | Token 格式非法（不含 `BANK_TOKEN_` 前缀）的请求，系统应统一拒绝 | 返回 HTTP 401 |
| REQ-43 | 注册 / 登录接口应防范 SQL 注入内容被写入数据库 | 数据库中不存在注入内容，或直接拒绝请求 |

### 2.6 并发与稳定性模块（Concurrency）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-44 | 多个请求并发对同一账户发起超出余额的取款时，系统应通过数据库事务锁保证最终余额不为负数（防超额透支竞态） | 最终余额 ≥ 0，实际成功扣款笔数 × 单笔金额 ≤ 初始余额 |

### 2.7 KYC 文件上传模块（Upload）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-45 | 用户可上传 JPG / PNG / PDF 格式的身份证件（KYC）文件 | 上传成功，返回文件信息及 `pending_review` 状态，HTTP 200 |
| REQ-46 | 不支持的文件类型（如 .exe / .zip）应被拒绝 | 返回 HTTP 400，提示"不支持的文件类型" |
| REQ-47 | 单文件大小超过 5MB 应被拒绝 | 返回 HTTP 400，提示"文件大小超过限制" |
| REQ-48 | 上传空文件（0 字节）应被拒绝 | 返回 HTTP 400，提示"文件不能为空" |

### 2.8 异步报表模块（Async Report）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-49 | 用户提交报表生成任务后，系统立即返回 `task_id`，状态为 `processing` | HTTP 200，data 包含 task_id 和 state=processing |
| REQ-50 | 用户可通过 `task_id` 轮询任务状态，任务完成后返回报表结果 | 最终 state=done，result 包含账务统计数据 |
| REQ-51 | 查询不存在的 `task_id` 时，系统应返回 404 | 返回 HTTP 404 |

### 2.9 第三方 Mock 测试（Mock Third-Party）

### 2.11 定期存款模块（Fixed Deposit）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-63 | 用户可开立定期存款（期限 1/3/6/12 个月，资金从活期账号划出） | 开立成功，返回 fd_id、到期日、预计利息，HTTP 200 |
| REQ-64 | 不支持的定期期限（如 2 个月）应被拒绝 | 返回 HTTP 400 |

| REQ-66 | 用户可查询本人所有定期存款列表 | 返回定期存款列表，HTTP 200 |

| REQ-68 | 已提前支取的定期不允许再次支取 | 返回 HTTP 400 |

### 2.12 交易流水模块（Transaction History）

| 编号 | 需求描述 | 期望结果 |
|---|---|---|
| REQ-69 | 用户可查询本人名下所有账号的交易记录（默认分页，最新优先） | 返回分页流水列表及总条数，HTTP 200 |
| REQ-70 | 支持按交易类型（存款/取款/转账/跨行汇款）过滤流水 | 过滤结果中所有记录的 txn_type 与过滤条件一致 |

| REQ-73 | 查询不属于自己账号的交易流水应被拒绝（水平越权） | 返回 HTTP 403 |
